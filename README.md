# Asan Office - Offline First Suite

Asan Office is a high-performance, offline-first desktop application suite built with Tauri, Rust, and React.

## Apps

- **Asan Word**: Modern word processor powered by TipTap and ProseMirror.
- **Asan Sheet**: (Coming Soon)
- **Asan Slide**: (Coming Soon)
- **Asan PDF**: (Coming Soon)

## Tech Stack

- **Backend**: Tauri (Rust)
- **Frontend**: React, TypeScript, Tailwind CSS
- **Editor Engine**: TipTap / ProseMirror
- **File Handling**: docx-js, local-first storage

## Getting Started

1. Install dependencies: `pnpm install`
2. Run Asan Word: `pnpm dev:word`
