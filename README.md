# Asan Office - Professional Offline Suite

Asan Office is a high-performance, fully offline desktop productivity suite.

## 📥 How to Install (Windows)

After downloading the source code, you need to generate the installer:

1.  Ensure you have **Node.js** and **Rust** installed on your computer.
2.  Double-click `build_windows.bat` in this folder.
3.  Your `setup.exe` will be created in `src-tauri/target/release/bundle/msi/`.

For more details, see the [Windows Installation Guide](INSTALL_WINDOWS.md).

## 🚀 Key Applications

*   **📝 Asan Word**: Professional word processor.
*   **📊 Asan Sheet**: High-performance spreadsheet.
*   **📽️ Asan Slide**: Presentation editor.
*   **📄 Asan PDF**: Secure PDF viewer and annotator.
